#### Часть 1
Выполним выражение `2 + 3 * 4` в файле и в консоли. В REPL результат отображается автоматически, потому что
консоль, делая какие-либо вычисления сразу выводит результат. В файле же нужно указать специальную команду `print()` для
вывода чего-либо.
#### Часть 2
Добавим в файл task_1 код:
```python
course = "Python"
hours = 4 * 2
print(f"{course}: {hours} часов")
```
Выражения: `"Python"`, `4 * 2`, `f"{course}: {hours} часов"`

Инструкции (строчки кода): `course = "Python"`, `hours = 4 * 2`, `print(f"{course}: {hours} часов")` 

Литералы: `Python`, `4`, `2`

Имена, создаваемые при выполнении программы: `course`, `hours`
#### Часть 3
Версия Python - Python 3.14.7

AST (абстрактное синтаксическое дерево) узлы соответствующие:

`a == b` -> `True` - оба имени указывают на один и тот же объект int со значением 1000

`a is b` -> `True` - `b = a` копирует ссылку, значит a и b — один и тот же объект

`a == c` -> `True` - `int("1000")` даёт объект со значением 1000, значения равны

`a is c` -> `False` - `int("1000")` создаёт новый объект, отличный от того, на который указывает a

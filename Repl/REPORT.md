#### Эксперимент C
```Python

```
Вывод:
```

False
5.551115123125783e-17

```
Числа с плавающей точкой хранятся в двоичном формате, и значения 0.1, 0.2, 0.3 не представимы

а не 0.3. Сравнивать вещественные числа на точное равенство нельзя, нужно использовать math.isclose(a, b).

Контрольные вопросы:

Почему `len(symbol)` и `len(symbol.encode("utf-8"))` могут различаться? — Потому что `len()` для строки считает
символы Unicode, а для bytes - байты. UTF-8 - кодировка переменной длины: один символ занимает от 1 до 4 байт.
Буква «Я» занимает 2 байта, поэтому длины 1 и 2.

Что означают границы и шаг в записи `text[start:stop:step]`? - start - индекс начала (включается),
stop - индекс конца (не включается), step - шаг. Пропущенные значения: `start = 0, stop = len(text),
step = 1`. Отрицательный step идёт справа налево.

Почему строка считается неизменяемым объектом, хотя методы вроде `.upper()` возвращают измененный текст? -
Потому что `.upper()` не изменяет исходную строку, а создаёт и возвращает новую. Исходная строка остаётся прежней.

```Python
"""Консольная программа для оформления отчёта об эксперименте.

Запрашивает у пользователя имя исследователя, название эксперимента,

timesec = time * countruns
complsq = compl.real ** 2 + compl.imag ** 2


out1 = f"ЭКСПЕРИМЕНТ: {name_exp}"

out7 = f"Есть выполненные запуски: {bool(countruns)}"

len_symb = max(len(out1), len(out2), len(out3), len(out4), len(out5), len(out6), len(out7))

print("=" * len_symb)
print(out1)
print(out2)

print("name_exp:", type(name_exp))
```
